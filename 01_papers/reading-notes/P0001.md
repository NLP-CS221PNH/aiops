# P0001 — LILAC: Log Parsing using LLMs with Adaptive Parsing Cache

**Tác giả:** Zhihan Jiang; Jinyang Liu; Zhuangbin Chen; Yichen Li; Junjie Huang; Yintong Huo; Pinjia He; Jiazhen Gu; Michael R. Lyu. **Năm trích dẫn:** 2024. **Venue:** Proceedings of the ACM on Software Engineering.

**Đã đọc:** Abstract; Introduction mô tả thành phần và evaluation overview. Mức đọc `fulltext_selected_sections`; không đại diện cho systematic review toàn văn.

| Trường extraction | Nội dung |
|---|---|
| Tác vụ | LLM log parsing với cache |
| Observations / labels | Raw logs và demonstrations; templates đã xử lý dùng làm cache. |
| Phương pháp | LILAC dùng hierarchical candidate sampling/ICL và adaptive cache refining để giảm số lần gọi LLM, tăng tính nhất quán. |
| Evaluation / protocol | Loghub-2.0; grouping/template F1 cùng efficiency được mô tả; chưa extraction tất cả bảng/ablation. |
