# P0114 — LibreLog: Accurate and Efficient Unsupervised Log Parsing Using Open-Source Large Language Models

**Tác giả:** Zeyang Ma; Dong Jae Kim; Tse-Hsun Peter Chen. **Năm trích dẫn:** 2025. **Venue:** 2025 IEEE/ACM 47th International Conference on Software Engineering (ICSE).

**Đã đọc:** Abstract. Mức đọc `abstract_only`; không đại diện cho systematic review toàn văn.

| Trường extraction | Nội dung |
|---|---|
| Tác vụ | Unsupervised parsing bằng open-source LLM |
| Observations / labels | Groups log có static text tương tự, dynamic variables khác. |
| Phương pháp | LibreLog kết hợp fixed-depth grouping, Jaccard diversity retrieval, self-reflection và template memory; abstract dùng Llama3-8B. |
| Evaluation / protocol | LogHub-2.0; full split/hardware chưa extraction. |
