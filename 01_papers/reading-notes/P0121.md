# P0121 — LLM Meets ML: Data-efficient Anomaly Detection on Unstable Logs

**Tác giả:** Fatemeh Hadadi; Qinghua Xu; Domenico Bianculli; Lionel Briand. **Năm trích dẫn:** 2026. **Venue:** ACM Transactions on Software Engineering and Methodology.

**Đã đọc:** Abstract. Mức đọc `abstract_only`; không đại diện cho systematic review toàn văn.

| Trường extraction | Nội dung |
|---|---|
| Tác vụ | Anomaly detection trên unstable logs |
| Observations / labels | Log sequences có software/environment changes; dataset variants ADFA-U, LOGEVOL-U, SynHDFS-U, SYNEVOL-U. |
| Phương pháp | FlexLog ensemble ML với Mistral; thêm cache và RAG. |
