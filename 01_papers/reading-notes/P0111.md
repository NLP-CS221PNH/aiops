# P0111 — Stronger, Cheaper and Demonstration-Free Log Parsing with LLMs

**Tác giả:** Xiao, Yi; Le, Van-Hoang; Zhang, Hongyu. **Năm trích dẫn:** 2024. **Venue:** chưa xác minh; chỉ trích bản preprint.

**Đã đọc:** Abstract. Mức đọc `abstract_only`; không đại diện cho systematic review toàn văn.

| Trường extraction | Nội dung |
|---|---|
| Tác vụ | Demonstration-free log parsing |
| Observations / labels | Logs chưa gán nhãn, grouped batches. |
| Phương pháp | LogBatcher clustering partitions, cache matching rồi batch log trong prompt. |
| Evaluation / protocol | 16 public datasets; cần lấy setup/cost accounting đầy đủ trước so sánh số liệu. |
