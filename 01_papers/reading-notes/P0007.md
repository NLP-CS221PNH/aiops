# P0007 — Xpert: Empowering Incident Management with Query Recommendations via Large Language Models

**Tác giả:** Yuxuan Jiang; Chaoyun Zhang; Shilin He; Zhihao Yang; Minghua Ma; Si Qin; Yu Kang; Yingnong Dang; Saravan Rajmohan; Qingwei Lin; Dongmei Zhang. **Năm trích dẫn:** 2024. **Venue:** Proceedings of the IEEE/ACM 46th International Conference on Software Engineering.

**Đã đọc:** Abstract; §5.1; §6.1.1; §11. Mức đọc `fulltext_selected_sections`; không đại diện cho systematic review toàn văn.

| Trường extraction | Nội dung |
|---|---|
| Tác vụ | Gợi ý KQL investigation queries |
| Observations / labels | Incident context và KQL lịch sử từ 10 dịch vụ Microsoft. |
| Phương pháp | Similar-incident retrieval, LLM query generation và post-processing; Xcore dựa AST, syntax/semantic, sub-components và output schema. |
| Evaluation / protocol | 197666 train/validation/retrieval instances, 3000 test; test incidents xảy ra sau train, index offline giữ cố định. |
